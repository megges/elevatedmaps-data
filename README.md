# Elevated Maps: Daten

Daten zu den Storys auf https://elevatedmaps.com. Nur Aggregate und eigene Schätzungen, keine Werte einzelner Anlagen.
Je Story ein Ordner mit `README.md` (Spalten, Methode, Kernzahlen, Quellen) und CSV-Dateien.

| # | Ordner | Story |
|---|---|---|
| 1 | `abgeregelt/` | https://elevatedmaps.com/stories/abgeregelt/ |

Für KI-Agenten: `git clone --depth 1 https://github.com/megges/elevatedmaps-daten`, dann zuerst die `README.md` im Ordner der Story lesen.

## Lizenz

Die Lizenz richtet sich nach den Quellen, sie stehen in der `README.md` jeder Story. Dateien mit Orten und Namen aus OpenStreetMap stehen unter ODbL. Bei Weiterverwendung bitte Elevated Maps und die Quellen nennen.

Erzeugt von `pipeline/<story>/export_daten.py` im Repo elevatedmaps. Bitte nicht von Hand ändern.
