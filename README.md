# Elevated Maps: data

Data behind the stories on https://elevatedmaps.com. Aggregates and own estimates only, no values of individual units.
One folder per story, each with a `README.md` (columns, method, key figures, sources) and CSV files.

| # | Folder | Story |
|---|---|---|
| 1 | `abgeregelt/` | https://elevatedmaps.com/stories/abgeregelt/ (curtailment of wind and solar power in Germany) |

For AI agents: `git clone --depth 1 https://github.com/megges/elevatedmaps-data`, then read the `README.md` in the story folder first.
